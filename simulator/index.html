What this model does—and leaves out

Each strategy visits a fixed ranking of snippets and skips entries that do not fit. On-demand retrieval adds one tool call per snippet. Upfront context has an assumed 40 ms packing cost and no retrieval calls. Hybrid uses half the budget for upfront selection, then tries the on-demand order with the remaining budget.

Coverage counts required snippets present; it does not measure correctness. Different rankings confound retrieval and delivery effects. Latency excludes indexing, model generation, retries, and caching. The simulator does not implement GrapeRoot's actual architecture.
